## Setting scope, behavior and requirements

Each operation ID fixes its scope. Administrator rights do not determine who receives a setting, whether it is enforced, or whether its GUI is editable. User operations use the execution account; alternate-administrator execution does not select the interactive user. Presentation metadata is additive to catalog schema 1 and does not change states, handlers or saved-run recovery. Missing metadata remains unverified, including in external libraries.

These are declared configuration effects. RIDE does not yet inspect effective policy or its source; a configured registry value and an effective platform default do not prove active enforcement. GUI and target acceptance are tracked separately in the post-migration review. Requirements describe the setting, rather than subscriptions needed only for optional cloud management.
