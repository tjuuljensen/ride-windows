# Metadata library starter

Copy this directory into your own repository. Change the library namespace,
operation/group IDs and profile references together before publishing it.

The example registry marker is inert and does not configure a Windows feature.
The optional package group reuses the built-in 7-Zip operation. Review the
profile and preview changes before applying; package installation requires
elevation. Development lifecycle checks belong in disposable Windows VMs.

See `docs/CUSTOM-LIBRARIES.md` in the RIDE-Windows checkout
for manifest fields, validation, completion, references and saved-run recovery.
Keep that guide available when copying the example outside this checkout.
